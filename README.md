# Flightdeck — downloads

Binaries for [Flightdeck](https://github.com/Jackpkn/Flightdeck), a macOS activity
monitor and Claude Code cockpit. The source lives in a private repository; this one
exists because GitHub release assets inherit their repository's visibility, and a
download link has to work without a token.

**[Download the latest release](https://github.com/Jackpkn/Flightdeck-releases/releases/latest)**

## Install

1. Open the DMG and drag Flightdeck to Applications.
2. On first launch, right-click the app and choose **Open**.

Step 2 is needed until the app is notarised with an Apple Developer certificate.
macOS will say it cannot verify the developer; right-click → Open gives you a way
through, where double-clicking does not.

Requires macOS 14 or later. Universal: Apple silicon and Intel.
